# Team Glossary

| English term | Simple English definition | Arabic explanation | GRAVERSE example |
|---|---|---|---|
| Artifact | A human-made object left or still traveling beyond Earth | أثر/قطعة من صنع الإنسان في الفضاء | `ranger-7`, `perseverance` |
| Mission | A planned space operation | مهمة فضائية | Apollo 11 mission |
| Hardware | Physical equipment, not just software or data | العتاد/المعدات المادية | Lander, rover, instrument |
| Lander | A spacecraft designed to reach and stay on a surface | مركبة هبوط | `viking-1-lander` |
| Rover | A vehicle that moves across a surface | مركبة جوالة | `sojourner` |
| Orbiter | A spacecraft that travels around a body | مركبة مدارية | A spacecraft in orbit |
| Probe | A spacecraft sent to observe or measure | مسبار | `ranger-7` |
| Instrument | A device that measures or tests something | أداة علمية | `apollo-11-lrrr` |
| Surface equipment | Hardware deliberately left on a surface | معدات سطحية | Apollo descent stage |
| Destination | The body or region a record is associated with | الوجهة | Moon, Mars, deep space |
| Mission status | State of the mission as an operation | حالة المهمة | `completed`, `ongoing` |
| Hardware status | State of the physical object | حالة العتاد | `inactive`, `impacted` |
| Communication status | A derived interpretation of link state | حالة الاتصال المشتقة | Mission Control label |
| Lost contact | Communication ended; not proof of destruction | فقدان الاتصال لا يعني الدمار | A recorded status distinction |
| Impact | Collision with a surface, sometimes planned | ارتطام/اصطدام | Ranger 7 planned impact |
| Telemetry | Data sent by an operating system | القياسات المرسلة عن بُعد | GRAVERSE is not live telemetry |
| Provenance | Evidence showing where a claim came from | مصدر/سجل أصل المعلومة | `sourceIds`, `/sources` |
| Primary source | Original or institutional record closest to the event | مصدر أولي | NASA mission page |
| Citation | A reference supporting a claim | استشهاد/مرجع | Registered source record |
| Confirmed | Supported by an attached source under project rules | مؤكد وفق المصدر | Claim badge |
| Estimated | Approximate rather than exact | تقديري | Estimated value with note |
| Simulated | Computed by a teaching model | محاكاة تعليمية | `/simulations` |
| Unknown | Not established in the current record | غير معروف/غير مسجل | Honest empty value |
| Data note | A visible note about uncertainty or scope | ملاحظة بيانات | `dataNotes` |
| Relation graph | Structured links among records | رسم بياني للعلاقات | mission ↔ artifact |
| Server component | Component rendered without browser state | مكوّن على الخادم | Most content pages |
| Client component | Component requiring browser interaction/state | مكوّن على العميل | Search, quizzes, filters |
| Static generation | Building known pages ahead of time | توليد ثابت مسبقًا | `generateStaticParams` |
| Local storage | Browser-only saved data | تخزين محلي في المتصفح | Progress and favourites |
| App Router | Next.js file-based routing system | نظام التوجيه في Next.js | `src/app/` |
| TypeScript | JavaScript with static types | جافاسكربت بأنواع ثابتة | `Artifact`, status unions |
| Tailwind CSS | Utility classes for styling | أدوات تنسيق CSS | Responsive classes |
| WebGL | Browser technology for GPU graphics | رسومات ثلاثية الأبعاد في المتصفح | Orrery and games |
| Progressive enhancement | Optional enhancement that does not remove core access | تحسين تدريجي | 3D plus 2D fallback |
| Accessibility | Designing for different abilities and input methods | إمكانية الوصول | Keyboard, labels, reduced motion |
| RTL | Right-to-left layout | من اليمين إلى اليسار | Arabic interface |
| UX research | Observing how people use a product | أبحاث تجربة المستخدم | New visitor tests |
| QA | Repeatable checks against expected behavior | ضمان الجودة | Journey and link checks |
| Constructivism | Learners build meaning by connecting ideas | البنائية | Related records and prior knowledge |
| Inquiry-based learning | Learning by asking and investigating questions | التعلم القائم على الاستقصاء | Explorer and sources |
| Narrative learning | Learning through an organized story | التعلم السردي | Purpose → journey → legacy |
| Systems thinking | Understanding connected parts and effects | التفكير المنظومي | Mission/hardware distinction |
| Differentiation | A defensible reason a product stands out | التميز/الاختلاف | One collection, three ways in |
| Limitation | What the product does not claim or cover | حد/قيد | No live telemetry |
