## Level gates

### Level 1 — Beginner

- Explain GRAVERSE in one minute.
- Name Academy, Museum, Explorer.
- State own responsibility.
- State one limitation.

### Level 2 — Intermediate

- Demonstrate one actual workflow.
- Point to a repository path or source URL.
- Explain how the workflow serves the challenge.

### Level 3 — Expert

- Answer a follow-up question.
- Separate implementation fact, scientific fact, interpretation, and limitation.
- Explain what the evidence does not prove.

### Level 4 — Critical judge simulation

- Respond to a skeptical question in under 45 seconds.
- Avoid unsupported superlatives and NASA endorsement claims.
- Hand off to the correct owner when the question crosses roles.
