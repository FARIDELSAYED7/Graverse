# Coordinated GRAVERSE Demo Script

Target: 8–9 minutes. The Founder controls the browser and the team supplies short handoffs.

## Preparation

Run the recorded project preparation commands from `docs/DEMO_GUIDE.md`. Use a clean browser profile or reset local progress. Pre-open `/`, `/academy`, `/museum/apollo-11-lm-descent-stage`, `/explorer`, `/sources`, and `/mission-control`. Have a no-WebGL explanation ready.

## Sequence

| Time | Speaker | Action and line |
|---|---|---|
| 0:00–0:45 | Member 4 | State challenge, audience, and the problem of active missions overshadowing hardware legacy. |
| 0:45–1:20 | Founder | Home: “One verified collection, three ways in.” Show Academy/Museum/Explorer. |
| 1:20–2:40 | Member 2 | Academy: open `first-flight`, one lesson, one quiz. Explain guided learning and the limitation that completion is not measured mastery. |
| 2:40–4:20 | Member 1 | Museum: open Apollo 11 descent stage or another prepared record. Show purpose, science, fate, two statuses, sources, uncertainty. |
| 4:20–5:30 | Founder | Mission page and source-linked relationship; explain derived missions and typed data. |
| 5:30–6:30 | Member 3 | Explorer: switch modes, apply destination/decade filter, show list alternative, mention keyboard/no-WebGL path. |
| 6:30–7:10 | Founder | Mission Control: mission, hardware, derived communication. Say it is a recorded snapshot, not telemetry. |
| 7:10–7:45 | Member 4 | Sources and differentiation: one collection, three modes, evidence visible, heritage framing. |
| 7:45–8:30 | All | State limits: curated scope, no NASA endorsement, partial Arabic editorial localization, no screen-reader certification, no measured educational impact. Close with why the product answers the challenge. |

## Recovery lines

- WebGL unavailable: “The 3D layer is optional. The same information is available in the 2D map/list and HTML controls.”
- Local progress stale: “Progress is browser-local; we can reset or import a prepared file.”
- Source link slow: “The source registry and claim labels are the evidence path; the app does not rely on a live telemetry feed.”
- Unexpected unknown: “This is intentional: the product preserves uncertainty instead of guessing.”
- Time short: skip games and simulations; keep the artifact story, status distinction, source, and limitation.
