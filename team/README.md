# GRAVERSE Team Knowledge System

This folder is the team’s shared onboarding, research, QA, and competition-preparation system for the GRAVERSE NASA Space Apps Challenge project.

## How to use it

1. Everyone reads `00_TEAM_MASTER_HANDBOOK.md` and the shared foundation in `shared/`.
2. Each teammate reads their own handbook in full.
3. The Founder uses `FOUNDER_TECHNICAL_MASTERY_GUIDE.md` to lead integration and technical defense.
4. The team works from `shared/DEMO_SCRIPT.md`, records evidence in `shared/EVIDENCE_REGISTER.md`, and tracks uncertainty in `shared/OPEN_QUESTIONS.md`.
5. Readiness is measured with `shared/TEAM_READINESS.md`, not with confidence alone.

## Important project-protection rule

The application is already built. The work described here is research, learning, QA, evidence collection, and presentation preparation. No teammate other than the Founder may modify production code, and the Founder should not modify it during this preparation phase unless the team explicitly begins a separate approved change task.

## Authority order

For an implementation claim, use the current repository. For a challenge requirement, use the official NASA Space Apps Challenge statement. For a scientific claim, use the cited NASA, JPL, NSSDCA, ESA, or other primary source. For educational theory, use the cited research source. When evidence is missing, say so.
