# الأسطح المساندة والمحاكيات

`/mission-control` يعرض ملخص status، communication وfreshness عبر `StatusBoard`. `/engineering` يشرح قرارات وتصميمات. `/stories` يحول السجل إلى narrative. `/research` و`/sources` يرفعان الشفافية. `/compare` يضع سجلات جنبًا إلى جنب. `/my-universe` يحفظ اختيارات شخصية محليًا. `/search` يبحث في artifacts والمحتوى. `/api/export` يقدم dataset بصيغة قابلة للاستهلاك.

Academy Play يضم Moon phases، Rocket workshop، Rover quest/map، مشاهد WebGL وbadges. `src/data/simulations.ts` يعرّف metadata، و`components/simulations/Simulators.tsx` ينفذ الحسابات التعليمية. يجب وصفها «نماذج تفاعلية» لا «تنبؤات».

Robot Lab وkids موجهتان للمبتدئين؛ لا ينبغي تقديم robot chat كوكيل NASA أو مصدر مستقل. Gallery Canvas يستخدم الصور والمرئيات، مع احترام fallback والحركة.

هذه الأسطح لا تنافس التجارب الثلاث على المركز؛ هي مداخل متخصصة: حالة، هندسة، قصة، بحث، مقارنة، شخصية، أو تجربة.
