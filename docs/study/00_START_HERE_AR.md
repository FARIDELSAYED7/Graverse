# ابدأ من هنا

## GRAVERSE في جملة

GRAVERSE متحف رقمي تفاعلي لعتاد استكشاف الفضاء المتروك على القمر والمريخ وفي الفضاء العميق؛ يحوّل السجلّ التقني إلى ثلاث طرق للفهم: **Academy للتعلّم، Museum للفهم، Explorer للاكتشاف**.

## المشكلة والحل

التحدي لا يطلب قائمة مركبات فقط، بل قصة تصل بين العتاد والغرض والمهمة والعلم الذي أصبح ممكنًا. الحل يحفظ هذه السلسلة في سجلات موثقة، ثم يعرض السجل نفسه كتعلّم منظّم، قطعة متحفية، وخط زمني/خريطة قابلة للاستكشاف.

## خمس أفكار يجب حفظها

1. المهمة قد تنتهي بينما يبقى العتاد أو يستمر في السفر.
2. `missionStatus` و`hardwareStatus` حقلاّن مختلفان عمدًا.
3. الاتصال حالة ثالثة مشتقة بحذر، وليس بثًا حيًا.
4. `confirmed / estimated / simulated / unknown` تجعل حدود المعرفة مرئية.
5. التقنية هنا تخدم الفهم: المرئيات لا تحل محل المصدر.

## حدود يجب قولها

المجموعة منتقاة وليست جردًا كاملًا لكل آثار NASA. لا يوجد telemetry حي. لا ينبغي تحويل حالة `operating` إلى ادعاء اتصال لحظي. المحاكيات حسابات تعليمية وليست قياسات جديدة.
